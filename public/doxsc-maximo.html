Gateway de Pagamentos PIX Ultra-Rápida

Integre cobranças PIX instantâneas em qualquer site, bot do Telegram ou checkout externo. Suporta roteamento para sua própria conta **VizzionPay**, **LulaPay** ou **Chave PIX Direta**, controle de repasse de dados do pagador (CPF/Nome dinâmico, aleatório, fixo ou omitido), camuflagem de nome de produto e verificação automática de pagamento em tempo real.

Onde obtenho meu Client ID (`ci`) e Client Secret (`cs`) e configuro minha Gateway?

Acesse /paineladmin2. Na aba **Minha Gateway PIX**, você pode conectar suas chaves da VizzionPay ou LulaPay, definir o tempo de expiração do PIX (padrão **30 minutos**) e escolher quais dados do cliente são enviados para a gateway.

Endpoints Disponíveis

POST
/api/v1/pix/create
Alias: /api/gateway/pix-create
Gera uma nova cobrança PIX imediata e retorna o QR Code e o código Copia e Cola (EMV). Tempo padrão de expiração: **30 minutos** (configurável no painel).

Headers de Autenticação (Aceita ci/cs ou Bearer Token)

Content-Type: application/json
ci: <SEU_CLIENT_ID> (ou x-client-id)
cs: <SEU_CLIENT_SECRET> (ou x-client-secret / Authorization: Bearer ...)

Corpo da Requisição (JSON) — Apenas amount é obrigatório

{
  "amount": 21.87,
  "payerName": "Nome do Cliente",       // Opcional (aceita também "name" ou "customer_name")
  "payerDocument": "12345678909",       // Opcional (aceita também "cpf" ou "document")
  "payerEmail": "cliente@email.com",    // Opcional (aceita também "email")
  "payerPhone": "11999999999",          // Opcional (aceita também "phone")
  "description": "Assinatura Mensal",   // Opcional (aceita também "productName")
  "webhookUrl": "https://seusite.com/webhook", // Opcional (sobrescreve o webhook do painel)
  "externalRef": "pedido_1029"          // Opcional (seu ID interno de referência)
}

💡 **Repasse Inteligente de Dados:** Se você não enviar `payerDocument` ou `payerName`, a API gera automaticamente um **CPF válido inédito** e um nome realista a cada cobrança (ou segue a regra Fixo / Aleatório / Omitir que você configurar em `/paineladmin2`).

GET / POST
/api/v1/pix/status
?transactionId=...
Consulta em **tempo real** diretamente na gateway processadora (VizzionPay / LulaPay) e no cache de baixa latência se o PIX foi pago (`pending`, `paid`, `cancelled`).

Exemplo de Chamada (GET ou POST)

GET https://seu-dominio.onrender.com/api/v1/pix/status?transactionId=d92f8a10-4b22-4d91-9e1a-8f12c9012345

Resposta 200 OK

{
  "success": true,
  "data": {
    "transactionId": "d92f8a10-4b22-4d91-9e1a-8f12c9012345",
    "amount": 21.87,
    "status": "paid",
    "payerName": "Nome do Cliente",
    "description": "Assinatura Mensal"
  }
}
GET
/api/v1/transactions
?limit=50&status=paid
Lista as transações geradas pela sua conta API e sincroniza automaticamente o status das cobranças pendentes mais recentes com a gateway.
GET https://seu-dominio.onrender.com/api/v1/transactions?limit=20
POST
/api/v1/pix/webhook
Recebe notificações de liquidação PIX da VizzionPay / LulaPay e encaminha automaticamente um POST JSON para a URL de Webhook configurada na sua conta.

Payload enviado para o seu Webhook quando o PIX é pago:

{
  "event": "payment.completed",
  "timestamp": "2026-11-10T22:30:00.000Z",
  "data": {
    "transactionId": "d92f8a10-4b22-4d91-9e1a-8f12c9012345",
    "status": "paid",
    "amount": 21.87,
    "payerName": "Nome do Cliente",
    "payerDocument": "12345678909",
    "description": "Assinatura Mensal"
  }
}
